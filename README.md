# first_project

一个判断闰年的小工具。

## 用法

```bash
# 检查当前年份
./leap.py

# 检查指定年份（可传多个）
./leap.py 2024
./leap.py 1900 2000 2023

# 脚本里用，只输出 yes / no
./leap.py -q 2024
```

退出码：全部为闰年返回 `0`，否则返回 `1`。

## 规则

公历闰年：能被 4 整除，但不能被 100 整除；能被 400 整除的年份仍为闰年。

| 年份 | 闰年 |
|------|------|
| 2024 | ✅ |
| 2023 | ❌ |
| 1900 | ❌（整百年且不能被 400 整除） |
| 2000 | ✅（能被 400 整除） |
